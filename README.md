# テーマ：「地形制約を考慮した『歩ける中心軸』の定量化 ― Space Syntax × 勾配による徒歩ネットワーク評価 ―」

## 概要（Overview）

本研究では、地形勾配が都市の歩行可能な中心構造にどの程度影響を与えているのかを明らかにすることを目的とする。

Space Syntax によって得られる道路セグメントの統合度（integration)は、都市構造上の中心性を表す指標として広く用いられている。一方で、丘陵地を多く含む都市では、勾配という物理的制約が実際の歩行行動を大きく制限している可能性がある。

本研究では、Space Syntax 指標と地形勾配を組み合わせることで、理論的に中心的でありながら、実際に歩行可能な道路ネットワークがどの程度残るのかを検討する。

## I. Introduction（背景・問い・位置づけ）

**背景**

- 15分徒歩圏（15-minute city）の議論では「徒歩でアクセスできる範囲」が重要だが、space syntaxの中心性（integration）だけだと、丘陵地では**実際の歩きやすさ（勾配負荷）**を取りこぼす。
- 先行研究は、**勾配を歩行基準で分類**し、**高integrationと低勾配を重ねる**ことで「walkable street network」を抽出している。

**研究問**

- *15分徒歩圏内で、Space Syntax上の主要軸（integration上位）が、勾配条件によってどれだけ“歩けるネットワーク”として残るか（延長で評価）*

**新規性（日本に寄せる）**

- 先行研究はトルコの基準（例：0–4, 4–7…%）で勾配を区分し、低勾配×高integrationを抽出している。
- 本研究はそれを踏まえつつ、**日本の前提に合わせて「許容勾配＝8%」**を主軸に設定し、15分徒歩圏での“残る骨格”を定量化する（延長で比較）。

## M. Methods（データ・手順・指標の定義）

**対象**

- 新百合ヶ丘駅を中心とする**15分徒歩圏ポリゴン**。

**データ**

- segment_map（道路セグメント）
    - 属性：integration（＋choiceがあれば後で拡張可）
- DEM由来の slope（% と度）
    - 本解析は **平均勾配（mean_slope%）を主**、最大勾配は補助。

**処理フロー**

1. segment_map を15分徒歩圏でクリップ
2. slope ラスタから segment_map 各線へ平均勾配（mean_slope%)を付与（結合まで完了済み、という説明でOK）
3. 閾値設定
    - **高integration：上位20%（integration ≥ 1392.4888）**
    - **低勾配：mean_slope% ≤ 8%（許容、中心）**
    - **低勾配：mean_slope% ≤ 5%（快適）**
4. オーバーレイ（AND抽出）
    - 「高integration（≥1392.4888）かつ低勾配（≤8.1%）」を重ねてwalkableを抽出。
5. 評価：**延長（m or km）**で比較（件数ではなく長さ）

**4パターン**

- P1：integration上位20%（構造のみ）
- P2：mean_slope% ≤ 8%（地形のみ）
- P3：P1 ∩ P2（本命：歩ける中心軸）
- P4：P1 ∩（mean_slope% > 8%）（対照：中心軸だが坂が障壁）

**データの内訳**

- Integration
    - 等量分類
    
    | 区分 | 意味 |
    | --- | --- |
    | Very high | 上位20% |
    | High | 60–80% |
    | Medium | 40–60% |
    | Low | 20–40% |
    | Very low | 下位20% |
- Slope
    - 
    - 日本ver （勾配凡例）
        - **0–1%**：ほぼ平坦
        - **1–5%**：バリアフリー的に「望ましい」側（5%が節目）
        - **5–8%**：「やむを得ない」許容側（8%が節目）
        - **8–12%**：基準超（1/8=12.5%は別文脈で出るので上限目安にしやすい）
        - **>12%**：急（多くの人が回避・負担）

## D. Discussion（解釈・先行研究との接続・限界）
本研究では、先行研究（walkability と Space Syntax を結びつけた分析枠組み）を参照し、新百合ヶ丘駅周辺を対象に、街路セグメントの Space Syntax 指標と勾配条件を重ね合わせて「歩ける中心軸」を抽出した。
その結果、**統合度（integration）上位20%のうち、平均勾配8%以下に該当する中心軸の延長は全体の約17%**にとどまり、統合度が高い＝歩行において実質的に“使われる中心軸”とは限らないことが示唆された。すなわち、Space Syntax 指標のみで walkability を評価するのではなく、地形（勾配）を道路ネットワークの制約条件として統合する必要がある点は、先行研究の主張と整合的である。

一方で、本解析は **解析半径を Rn（全体半径）**として算出した指標に基づいており、歩行行動（特に高齢者の近隣移動）の説明を強めたい場合には、より小さい半径（例：R800–R1600m 等）での感度分析を行うことが課題である。半径を変えることで「中心軸」の位置や強度が変化する可能性があり、歩行スケールに適した半径設定を検討する必要がある。

また、分析範囲については、駅を起点とした 15分徒歩圏ポリゴンで道路をクリップして用いたが、この「15分徒歩圏」はあくまで分析範囲を限定するための操作的定義であり、そのまま **15分都市（生活機能が15分で完結する都市構造)**を主張できるわけではない。新百合ヶ丘では、徒歩圏外からバス等で駅へアクセスする利用実態も想定されるため、今後「15分都市」を卒論テーマとして扱う場合は、徒歩だけでなく公共交通・生活施設配置なども含めた定義づけが必要になる。

今後の発展としては、比較対象地域を設定し、**地形条件（多摩丘陵・谷戸地形）や人口構成（高齢化）**と、今回の指標（NAIN/NACH、integration/choice、勾配条件による残存率）との対応を検討したい。具体的には、平均寿命が高いという共通点を持つ 麻生区と青葉区を候補とし、両地域における「中心軸が歩ける形で残る割合（延長ベース）」や、ネットワークの読みやすさ（例：NAIN–NACHの関係、R²）を比較することで、空間構造の共通点／差異を明らかにすることが次の課題である。

## C. Conclusion　
散布図より、一般的にR²:0〜0.5の範囲だと空間的な識別が弱いと論文で指摘されている。今回はo.09という結果から到達性（NAIN）と通過性（NACH）の線形関係は弱く、局所的に“通り抜けやすい”道が必ずしも“行き着きやすい”骨格と一致しない可能性が示唆される。

15分徒歩圏内に含まれる道路ネットワークの総延長は 122.8 km であった。
integration上位20%に該当する道路は、延長ベースで約31%を占めた。一方、平均勾配8%以下の道路は約43%であった。

しかし、両条件を同時に満たす「高統合かつ低勾配」の道路延長は全体の約17%にとどまった。
これは、空間構造上の中心性が高い道路の多くが、地形条件を考慮すると歩行上の主要軸としては機能しにくいことを示している。
